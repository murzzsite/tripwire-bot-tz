# ТЗ: бот @Napominaskhabot (слэш-команды) + доработка Tripwire Generator

Начни с файла **`ТЗ_Бот_и_Сайт_Tripwire.docx`** — это полное техническое задание (v4):

- Часть А — 22 слэш-команды для бота-помощника менеджеров, тексты + картинки уже готовы
- Часть Б — доработка Tripwire Generator (45.10.40.120): новый шаг «Сайт» в пайплайне клиента + принцип «клиент никогда не заходит в сам Tripwire, только по отдельным ссылкам ревью»
- Открытые вопросы — в конце документа (раздел 9)

Файл `Памятка_менеджера_слэш_команды.docx` — не для реализации, а для менеджеров, которые будут привыкать к новым командам (справочная таблица «раньше писали руками → слэш-команда»).

Папка `media/` — все картинки и видео, на которые ссылается ТЗ (10 картинок + 2 видео), под теми же именами файлов, что упомянуты в тексте.
